## 2026-11-17 — 변수·타입·연산자, 그리고 정수 나눗셈

- 한 일: `02a-변수와타입.cs`(int/string/bool/double·`var`·`const`)와 `02b-연산자.cs`(산술·비교·논리·대입)를 작성. `dotnet run src/01-basics/02b-연산자.cs`로 파일 하나만 실행.
- 막힌 점: `10 / 3`의 결과가 `3.33`이 아니라 `3`으로 나옴. 왜 소수점이 사라지는지 처음엔 이해 못 함.
- 시도 → 해결: 두 피연산자가 모두 `int`라 **정수 나눗셈(몫만)** 이 되는 것. `10.0 / 3` 또는 `(double)10 / 3`으로 바꾸니 `3.333...` 출력.
- 배운 점: 개념 강의에서 "CPU는 정수와 실수를 다르게 처리한다"고 들은 게 여기서 체감됨. **타입이 연산 결과를 바꾼다** — 계산 전에 타입을 먼저 본다.
